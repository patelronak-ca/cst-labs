# CST Labs – Ronak Patel

Hands-on labs and projects from the **Computer Systems Technician** program at **St. Lawrence College** (Cornwall, Ontario), covering cloud, scripting, Linux, Windows Server, and networking.

## Highlights

- **PowerShell System Health Report:** collects computer name, OS, CPU, disk space, RAM, and uptime into a report, with error handling
- **Linux Shared Folder Access Control:** team folders secured with groups, permissions, ACLs, and setgid, including troubleshooting a misconfigured folder
